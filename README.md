# Jennie's Heating & Cooling Website

Official website for Jennie's Heating & Cooling, family owned and operated since 1994, serving Hampton Roads, Northeastern North Carolina, and the Outer Banks.

## Structure

Plain HTML site, no build step required.

- index.html - Home
- products-services.html - Products & Services
- warranties.html - Warranties
- employment.html - Employment
- contact.html - Contact Us
- CNAME - custom domain configuration for GitHub Pages (jenniesheatingcooling.com)

## Hosting

Served with GitHub Pages from the main branch root. To update the site, edit or replace the HTML files and commit; GitHub Pages redeploys automatically within a minute or two.
